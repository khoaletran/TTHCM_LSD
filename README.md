# Ôn Tập & Luyện Thi — Tư Tưởng Hồ Chí Minh & Lịch Sử Đảng

Ứng dụng web học tập và luyện câu hỏi trắc nghiệm hiện đại cho 2 học phần:
- **Tư tưởng Hồ Chí Minh** (707 câu hỏi, 6 chương)
- **Lịch sử Đảng Cộng sản Việt Nam** (736 câu hỏi, 4 phần/chương)

Tổng cộng **1.443 câu hỏi** trắc nghiệm chuẩn chỉnh kèm đáp án và giải thích chi tiết.

---

## 🌟 Điểm nổi bật

- **100% Client-side**: Hoạt động hoàn toàn trên trình duyệt, không cần tài khoản, không cần mật khẩu, không gửi dữ liệu ra máy chủ bên ngoài.
- **Ngân hàng câu hỏi đầy đủ**: Tra cứu, tìm kiếm từ khóa, lọc theo chương, xem đáp án và giải thích.
- **Phòng luyện tập đa dạng**:
  - Luyện theo từng chương.
  - Luyện trộn toàn bộ ngân hàng câu hỏi.
  - Thi thử Giữa kỳ & Cuối kỳ (có đồng hồ đếm ngược).
  - Chế độ xem đáp án ngay sau mỗi câu (Học tập) hoặc nộp bài chấm điểm một lần (Thi thử).
- **Cử chỉ vuốt chạm (Touch Swipe)**: Hỗ trợ vuốt trái/phải trên màn hình điện thoại/tablet để chuyển câu tự nhiên, mượt mà. Phím mũi tên `←` / `→` trên máy tính.
- **Bảng điều hướng câu hỏi (Quiz Navigator)**: Lưới câu hỏi 01..N theo dõi tiến độ, nhảy nhanh đến câu bất kỳ.
- **Ôn câu hay sai**: Tự động ghi nhớ câu làm sai để ôn tập dứt điểm lỗ hổng kiến thức.
- **Thẻ ghi nhớ (Flashcards)**: Lật thẻ tương tác ghi nhớ các mốc năm, sự kiện và định nghĩa quan trọng.
- **Giao diện hiện đại**: Hỗ trợ Chế độ Sáng / Tối (Dark & Light theme), responsive tối ưu trên mọi kích thước màn hình.

## 🚀 Cài đặt & Chạy cục bộ

```bash
# 1. Cài đặt dependencies
npm install

# 2. Chạy môi trường phát triển
npm run dev

# 3. Build cho môi trường production
npm run build
```
